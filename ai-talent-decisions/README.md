# Talent Calls, Sharper · Sharper Inputs, Human Calls

A short interactive course (Classroom 40 min / Core 30 / self-paced ~15) for
leaders on AI in hiring, succession, and skills mapping: AI drafts the
instruments (rubrics, structured interview questions, skills maps,
succession profiles) and every verdict about a person stays human. Part of
the AI-enabled Education Series and the Manager Voyage.

Part of the Vanderbilt Learning Series. Catalog:
[Course Library](https://me5231979.github.io/Course_Library/)

- **Learner edition:** https://me5231979.github.io/Course_Library/ai-talent-decisions/
- **Facilitator edition:** https://me5231979.github.io/Course_Library/ai-talent-decisions/facilitator/

## What it teaches (3 sections)

1. Instruments, not verdicts: the line that keeps talent AI useful and
   defensible, with the strictest data rules in the series (resumes,
   reviews, and names are red; candidate work runs with HR)
2. The Rubric Lab: build a defensible 9-box (source, criteria, anchors,
   scoring), graded; the same build makes the structured interview kit
3. Skills, gaps, and growth: de-identified skills maps, inference as
   draft, grow-borrow-hire, and succession profiles without names

Ends with a scored recap, the **Talent Toolkit Card capstone**, a
flip-card glossary, printable cheat sheet, and toolkit card worksheet.

## The interactive tools

| Slide | Tool | What learners do |
|---|---|---|
| The line | **Draft, call, or keep it out?** | Sort five talent tasks against the line |
| The rubric | **The Rubric Lab** | Build a 9-box in four graded choices, then run the talent review |
| The skills map | **Useful and safe?** | Call five skills-work moves on usefulness and data safety |
| Recap | **Scored quiz** | 4 questions mapped to the objectives |
| Capstone | **My Talent Toolkit Card** | Commit to one instrument with a dated build session |
