Vanderbilt · Staff Learning Collection

SCORM packages.

Each download is the self-paced edition of one course, wrapped as a SCORM 1.2 package for upload to an LMS (Oracle Learning, Cornerstone, Moodle, Canvas with a SCORM tool, SCORM Cloud, and similar). On launch the package reports itself complete to the LMS; exercises still run entirely on the learner's device (privacy note). Links that leave the course (the catalog, other courses) open the live site in a new tab.

Upload notes

Import the zip as-is; do not unzip it first. The launch file is declared in imsmanifest.xml. Completion is recorded at launch (status completed); scores are not reported, since the in-course checks are self-scored by design. Rebuild any package after a course change with tools/build-scorm.py.
